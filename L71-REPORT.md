# Control UI shell style and layout experiment

Experiment only; do not merge. Measurement in progress against the synthetic Team-scale fixture.

Scope: style recalculation, selector statistics, layout attribution, and isolated containment candidates. No production behavior changes yet. Private campaign captures are excluded.
