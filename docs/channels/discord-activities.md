Discord Activities are no longer supported. Plugin widget presenters and their
Discord integration were removed with the retired Plugin SDK capabilities.
Remove the `activities` setting from your Discord channel configuration.

Discord messaging and voice remain supported. Core Canvas widgets still work
in clients that support inline widgets. See
[retired plugin capabilities](/plugins/sdk-migration/removed-surfaces#retired-plugin-capabilities)
for the complete removal list.
